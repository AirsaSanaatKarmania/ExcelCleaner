# Excel Cleaner — پاک‌سازی ارقام و تبدیل اکسل به «شکل خام»

[![Tests](https://github.com/AirsaSanaatKarmania/ExcelCleaner/actions/workflows/tests.yml/badge.svg)](https://github.com/AirsaSanaatKarmania/ExcelCleaner/actions/workflows/tests.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

[English README](README.en.md)

برنامه‌ی ویندوزِ ساده برای کسانی که با فایل‌های اکسلِ فارسی کار می‌کنند: شماره کارت، کد پرسنلی و کد ملی را **بدون خراب شدن** (نماد علمی، صفرهای اول، ارقام فارسی، خط تیره) به مقدار خام تبدیل می‌کند و در صورت نیاز تمام قالب‌ها و فرمول‌ها را هم پاک می‌کند.

## امکانات

- تبدیل ارقام فارسی و عربی به انگلیسی: `۱۲۳` ← `123`
- تبدیل متن‌های عددی با جداکننده به عدد خام: `5892-1041-0085-9016` ← `5892104100859016`
- حفظ صفرهای اول (`۰۰۱۲۳` ← `00123`) و شماره کارت ۱۶ رقمی (به صورت متن)
- **انتخاب دلخواه سلول‌ها** با کشیدن ماوس، Ctrl+کلیک، کلیک روی ستون/ردیف یا نوشتن آدرس مثل `B2:B500, D:D, 5:8`
- **تبدیل به شکل خام** برای سلول‌های انتخاب‌شده، کل شیت یا همه شیت‌ها:
  - فرمول ← مقدار
  - حذف قالب سلول‌ها (فونت، رنگ، حاشیه، فرمت عدد، ...)
  - باز کردن ادغام سلول‌ها
  - حذف لینک، کامنت، قالب‌بندی شرطی، Validation، جدول (Table) و فیلتر
  - حذف فاصله‌های اضافی ابتدا و انتهای متن
- فایل اصلی دست‌نخورده می‌ماند؛ خروجی با پسوند `_fixed` ذخیره می‌شود
- سلول‌های تغییرکرده در جدول برنامه سبز می‌شوند و تا قبل از ذخیره می‌توانید همه‌چیز را لغو کنید

## دانلود (بدون نصب پایتون)

از بخش [**Releases**](../../releases/latest) فایل `ExcelCleaner.exe` را دانلود و اجرا کنید.

> اگر ویندوز یا آنتی‌ویروس هشدار داد: برنامه‌های ساخته‌شده با PyInstaller گاهی به اشتباه هشدار می‌گیرند. می‌توانید برنامه را از سورس اجرا کنید یا خودتان exe را بسازید (پایین‌تر توضیح داده شده).

## اجرا از سورس

پایتون ۳.۹ یا بالاتر لازم است (هنگام نصب، گزینه‌ی **Add Python to PATH** و **tcl/tk** را فعال کنید).

```bash
git clone https://github.com/AirsaSanaatKarmania/ExcelCleaner.git
cd excel-cleaner
py -m pip install -r requirements.txt
py excel_cleaner.py
```

## ساخت فایل exe

روی ویندوز فایل `build_exe.bat` را دابل‌کلیک کنید؛ خروجی در `dist\ExcelCleaner.exe` ساخته می‌شود.

یا از طریق GitHub Actions: یک تگ مثل `v1.0.0` بسازید و push کنید تا exe به‌صورت خودکار به Releases اضافه شود.

## راهنمای استفاده

1. **فایل اکسل** (`.xlsx` یا `.xlsm`) را انتخاب کنید و در صورت نیاز شیت را عوض کنید.
2. **سلول‌ها را انتخاب کنید** (برای شکل خام می‌توانید به‌جای آن «کل شیت» یا «همه شیت‌ها» را بزنید).
3. برای ارقام و شماره‌ها: تنظیمات بخش ۳ را بررسی کنید و «اعمال تبدیل ارقام/جداکننده» را بزنید.
4. برای پاک کردن قالب و فرمول: گزینه‌های بخش ۴ را انتخاب کنید و «تبدیل به شکل خام» را بزنید.
5. **ذخیره فایل جدید** را بزنید.

## چرا شماره کارت در اکسل خراب می‌شود؟

اکسل در نوع Number فقط **۱۵ رقم معنی‌دار** نگه می‌دارد. شماره کارت ۱۶ رقمی را به نماد علمی (`5.8921E+15`) تبدیل می‌کند و رقم آخر را صفر می‌کند؛ این رقم بعداً قابل بازیابی نیست. شماره کارت یک شناسه است، نه عدد، و باید به صورت **Text** ذخیره شود. به همین دلیل خروجی پیش‌فرض این برنامه متن است. برنامه سلول‌های عددی ۱۶ رقمی را که احتمالاً از قبل خراب شده‌اند شناسایی و هشدار می‌دهد.

## محدودیت‌ها

- فقط `.xlsx` و `.xlsm` پشتیبانی می‌شود (فایل `.xls` را ابتدا در اکسل با Save As تبدیل کنید).
- فایل با کتابخانه‌ی openpyxl ذخیره می‌شود؛ نمودار، تصویر و Pivot Table ممکن است در خروجی حفظ نشود. قبل از استفاده روی چنین فایل‌هایی یک کپی تست کنید.
- مقدار فرمول‌ها همان مقداری است که اکسل آخرین بار در فایل ذخیره کرده است. فرمولی که مقدار ذخیره‌شده ندارد دست نمی‌خورد و برنامه هشدار می‌دهد.
- تبدیل ارقام و جداکننده فقط روی شیت جاری اعمال می‌شود (مگر محدوده‌ی «همه شیت‌ها» در بخش شکل خام).
